插件介绍
这是一个面向 Aseprite 的实用扩展，核心思路是把网页工具中的“1.4材质图转1.3”与“精灵图转GIF”组合进同一工作流，方便在像素编辑器内一站式完成预览与导出。
点击输出选项中指定的动画帧可高亮查看主图中的哪块区域材质。
  • 支持 360×224（或同比例）输入，按 1~36 分片规则生成 40×1120（20 帧）盔甲图/手臂图。
  • 内置女性身体替换、指定帧上移 2px、序号标注、像素网格辅助等与网页版一致的关键选项。
  • 可将 20 帧结果同步到时间轴预览，直接在 Aseprite 中查看动画连贯性。
  • 将生成后的长图继续进行 GIF 化预览与导出，形成“转换 + 动画验证”闭环流程。
