关于 EasyXnb

EasyXnb 是一个面向 tModLoader 的 XNB 编译工具，可将着色器（.fx）、贴图（.png/.jpg/.bmp/.tga/.dds）和模型（.fbx）编译为 XNA 内容管线格式（.xnb）。
本页提供图形化界面来生成 App.config 配置文件；下载后放入 EasyXnb 的运行目录即可覆盖默认配置。

使用说明

          
    
            
  1. 从 GitHub 下载 EasyXnb（或使用本地已有版本）
    2. 
            
  2. 在本页配置好选项，点击「下载 App.config」
    3. 
            
  3. 将下载的 App.config 放入 EasyXnb.exe 同级目录（覆盖原有配置）
    4. 
            
  4. 把要编译的文件（.fx / .png / .fbx 等）放入输入目录
    5. 
            
  5. 运行 EasyXnb.exe，编译结果输出到输出目录
    6. 
          

          

            注意：EasyXnb 仅支持 Windows（依赖 XNA Framework），请在 Windows 环境下运行。
