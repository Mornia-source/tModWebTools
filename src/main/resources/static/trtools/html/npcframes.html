预览
闭眼帧（眨眼）手绘调整
左键用当前颜色绘制，按住可连续绘制；“吸管”或右键吸取颜色。“还原像素”可把单个像素恢复为自动生成的颜色。
动画
自动标记眼睛 / 嘴巴
左键标记眼睛（蓝色），右键标记嘴巴（粉色）；用按钮切换后左右键对调。同一像素只能是眼睛或嘴巴之一。闭眼帧会取眼睛旁的皮肤色覆盖并画黑线，说话帧在嘴巴处画黑色像素。
